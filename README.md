# RMF Security Assessment Sample

This project simulates a full Risk Management Framework (RMF) security assessment for a fictional state-level case management system.

The goal of this project was to walk through the RMF lifecycle in a practical way — not just theory — and document what a real security assessment process would look like from categorization through continuous monitoring.

I built this to demonstrate that I understand more than just SOC operations. I can also think in terms of governance, control selection, risk decisions, and authorization recommendations.

---

## What This Project Demonstrates

- Understanding of the NIST RMF lifecycle
- Security categorization using FIPS 199 concepts
- NIST SP 800-53 control selection and tailoring
- Security assessment planning
- Findings documentation and severity analysis
- ATO recommendation logic
- Continuous monitoring planning

---

## Frameworks Referenced

- NIST Risk Management Framework (RMF)
- NIST SP 800-53 Rev. 5
- FIPS 199 Security Categorization
- Continuous Monitoring best practices

---

## Why I Built This

Most entry-level candidates focus only on tools. I wanted to show that I understand how security decisions are made at a system level — how controls are selected, assessed, documented, and approved.

This bridges technical security knowledge with governance and risk management thinking.
